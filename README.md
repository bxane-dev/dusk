# Dusk

Dusk is an open-code desktop game launcher for managing locally installed
games, launching them, tracking playtime, organizing screenshots, themes,
achievements, and more.

## Planned features

- Automatic game detection
- Launch local games
- Steam library scanning
- Playtime tracking
- Game covers and banners
- Screenshots
- Favorites and collections
- Search, filters, and sorting
- Themes and customization
- Stats dashboard
- Manual game entries
- Emulator support
- Optional save backups

## Planned stack

- Tauri
- React
- TypeScript
- Rust
- SQLite
